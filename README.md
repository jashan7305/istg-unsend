# How It Works

1. Open Instagram in Firefox and navigate to the conversation containing the messages you want to unsend.
2. Open the **Instagram Unsend** extension.
3. Select a delay between **1 and 7 seconds**. This controls the pause between unsend operations.
4. Click **Unsend All**.

**works best when completely zoomed out**

The extension then:

- Scrolls through the conversation to load older messages.
- Continues until it reaches the oldest available messages.
- Processes your sent messages from oldest to newest.
- Opens each message's native options menu.
- Selects **Unsend** and confirms the action using Instagram's confirmation dialog.
- Moves to the next message after the selected delay.

You can click **Stop** at any time to stop the process.

The extension uses Instagram's existing interface to perform unsend operations.
